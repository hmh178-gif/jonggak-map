폐업·없는 곳 신고

신고만으로 바로 사라지지는 않아요. 관리자가 확인 후 숨겨요. 신고 수는 다른 사람에게도 보여요.

종각 맛집책 사용법처음 오셨나요?

1이 책은요

  • 종각역 반경 1km 안에서 인허가상 영업 중인 식당·카페를 모은 책이에요. (공공데이터 기준)
  • 목록은 종각역에서 가까운 순으로 나와요. 정렬 메뉴에서 별점순·좋아요순·찜 많은순·노포순으로 바꿀 수 있어요.
AI가 카카오 별점 못 불러옴!! 카카오·네이버는 별점을 가져오는 기능을 열어주지 않아서, 이 책의 ★별점은 전부 우리끼리 매긴 점수예요. 카카오 별점이 궁금하면 카카오 상세 버튼을 눌러 직접 확인해 주세요.

2분류 고르기

  • 노란 띠의 한식 양식 버튼은 여러 개를 같이 고를 수 있어요. (옆으로 밀어서 넘기기)
  • 넘기기 귀찮으면 분류: 전체 ▾ 드롭다운에서 하나만 골라도 돼요.
  • 치킨집·버거 체인은 패스트푸드·치킨에 모여 있어요
  • 🌶 매운맛 떡볶이·마라·쭈꾸미·낙지 같은 매운 집만 / 프랜차이즈 빼기 체인점 숨기기

3평가하기 (친구들과 합산)

  • ♥ 좋아요 ★ 별점 주기(1~5점, 한 사람 한 번·수정 가능) 📌 찜(가고 싶은 곳) 👎 별로
  • 처음 누를 때 닉네임을 물어봐요. 같은 닉네임을 쓰면 다른 기기에서도 내 기록이 이어져요.
  • 평가가 모이면 업소 칸에 ★별점 스티커가 붙고, 지도에는 큰 노란 점으로 보여요.

4모아 보기

  • ★ 평가된 곳 누군가 평가한 곳만 / 📌 내가 찜한 곳 내 찜 목록 / 👎 별로 숨김 별로가 좋아요보다 많은 곳 숨기기

5지도 보는 법

  • 점을 누르면 아래에 그 건물에 있는 업소 목록이 떠요. 지도 빈 곳을 누르면 전체로 돌아가요.
  • 두 손가락으로 확대·축소, 한 손가락으로 끌어서 이동해요.
  • 숫자 동그라미는 업소 묶음이에요. 확대하면 풀려요.
  • 🏠 종각역으로 돌아가기 · 📍 내 위치로 이동
  • 아래 검은 띠를 누르면 목록이 열리고 닫혀요.

6업소 칸의 버튼

  • ☎ 전화번호 누르면 바로 전화
  • 📍 지도에서 위치 또는 가게 이름을 누르면 지도가 그 위치로 이동해요
  • N 이름 검색 네이버지도에서 가게 이름으로 찾기 → 폐업했는지 한 번 더 확인
  • N 주소 검색 이름으로 안 나오면 건물 주소로 찾아서 그 건물 안 가게를 직접 확인
  • 카카오 상세 카카오맵 가게 상세페이지(별점·리뷰·메뉴)로 이동. 딱 맞는 가게를 못 찾으면 카카오 검색 목록을 열어줘요
  • 블로그 '내돈내산' 네이버 블로그 후기 검색
  • 🚫 폐업·없는 곳 신고 가보니 문을 닫았거나 지도에서 안 나오면 알려주세요. 관리자가 확인 후 책에서 빼요. 신고가 들어온 곳은 ⚠ 신고 표시가 붙어요

※ 공공데이터의 상호는 인허가 신고 이름이라 실제 간판과 다를 수 있어요. 이름으로 안 나오면 주소 검색을 써 보세요.
